# NXP Unity
Production reboot of NXP as a Unity URP mobile 2.5D/isometric action RPG/shooter.

## Target
- Unity 6 LTS / Universal Render Pipeline
- Android first, scalable quality presets
- Isometric perspective camera
- PBR cyberpunk environments, realtime VFX, animated characters
- Mission -> region -> boss progression
- Existing web prototype remains under /game as a mechanics reference

## First playable milestone
Neon District: player movement, camera follow, shooting, enemy pursuit, data cores, Mutant Brute boss, XP/credits, quality tiers.
